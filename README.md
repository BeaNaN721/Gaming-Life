# Gaming_Life

一个基于 NestJS 的每日任务积分系统，就像游戏中的每日任务机制。  
用户每天完成任务可以获得积分，并记录历史完成情况。  
通过这个项目，你可以学习 NestJS、TypeORM、ValidationPipe 以及基本的模块化后端设计。

---

## 功能

- 用户注册 / 登录
- 创建任务 / 查询任务列表
- 完成任务 → 积分累计
- 查询用户任务完成历史

---

## 技术栈

- NestJS
- TypeScript
- TypeORM + MariaDB
- ValidationPipe
- bcrypt（密码加密）
- Node.js v20+
